# Sages installed

Hermes installed the Sages repository into this directory and, once the plugin is enabled,
lists its nine skills as `sages:<skill>`.

Start a new session (`/new`) and say, for example:

    Who are the sages?
    What would Epictetus say about my boss taking credit for my work?
    Ask the council: should I take the job in another city?

`INSTALL_FOR_HERMES.md` in this directory has the verification steps, the optional
one-agent-per-teacher setup, and how to update or remove the plugin.
