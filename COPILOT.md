# COPILOT.md

GitHub Copilot CLI loads this file at session start. Coding agents working on this repository:
read [AGENTS.md](AGENTS.md).

To use the Sages skills from Copilot, install the pack through the shared `.claude-plugin/`
manifest (`copilot plugin marketplace add NTP-996/sages`). The skills use plain action words and
Copilot resolves its own tools for them.
